# 设计与可验证成果

[English](design.md) · [入门](quickstart.zh-CN.md) · [测试](testing.zh-CN.md)

基线为团队 0.1.36 及 [members.lock.json](../members.lock.json)，说明日期 2026-09-29。这是设计与验收说明，不是生产就绪声明。

## 职责与调用

目标编排为 **O0 注册 → O1 输入治理 → O2 抽取 → O3 法域/风险并行 → O4 独立复核 → O5 评分、报告与 DOCX → 组长交付**。O4、O5 是对同一个 `review-reporter` 身份的两次调用，不是新增成员。

| 步骤/负责人 | 可独立检查的最小成果 | 好/不合格的标准 |
|---|---|---|
| O0 / 组长 | 原文与版本身份、工作范围、覆盖账本 | 所有调用处理相同原文并保留已知缺口；混用版本或从产出反推覆盖即失败。 |
| O1 / 输入治理 | 输入清单、门禁、原因与下一步 | 每项输入问题有证据，缺件持续可见；把未决事实当完整即失败。 |
| O2 / 条款抽取 | 定位后的条款与可比较事实 | 每个数值可追溯，缺失、未知、不适用分开；编造数值或无依据认定不存在即失败。 |
| O3 / 法域审计 | 法域、服务范围与规则依据 | 域外给出转介且不作实体法律结论；把 CN-only 范围误写成缺外国知识包即失败。 |
| O3 / 风险扫描 | 有依据的风险、等级与动作 | 检查重要风险与反例；把存在但不利的条款当作缺失即失败。 |
| O4 / 复核报告 | 对每个候选事实重新取证 | 逐项确认、反驳、无法定位或新增，不读取前序推理；未回原文而照抄即失败。 |
| O5 / 复核报告 | 可解释评分、可行动报告、待决事项和修订文件 | 发现、建议修改和未决事项可追溯；无理由分数或声称存在而实际缺失的 DOCX 即失败。 |
| 交付 / 组长 | 可访问的最终产物与真实完成状态 | 明确限制和剩余工作；只看工具结束、把人工补救称自主成功即失败。 |

上述是自然语言目标和质量标准。机器格式可以服务现有工具接口，但格式合法不代表审查成果合格。

## 一致性指决定稳定

每次调用都需要同一原文身份、当事方立场、目标、范围、相关规则与完成标准。传递证据和未决事实，而非完整前序推理。核验委派实际使用的 provider/model。

同类输入应有稳定的**结果类别**：输入通过/条件通过/阻断；证据已验证/未验证；有依据风险/无支持的发现；域内/域外；报告交付/存在待决事项/交付失败。措辞无需逐字相同，也不需要新增通用业务 schema。

提示词不能保证每次执行绝对一致。固定版本进行三次独立运行，比较原文身份、必检项、禁止误报、范围、待决事项和产物完整性。类别变化必须有依据解释。

## 当前规则与未解决冲突

[shared/rules.md](../shared/rules.md) 声明自身优先且仍要求固定七步；[业务规则](../shared/resources/business-ontology/rules.md) 保留类似旧限制，尚未完整表达以上 O0–O5 设计。本次文档变更**不替换**注入规则，也不证明冲突已解决。

概念对应为：旧解析/完整性检查 → O1；抽取 → O2；法域/风险 → O3；版本比较分布于对应原文比较与报告工作；报告 → O5。O0 注册和 O4 独立复核仍需在运行规则中明确。旧规则禁止并步/重排的问题，需要另行审阅行为改动并真机回归。

同样，上游“已确认事实”在 O4 仍是待重新验证项，不能据此跳过独立检查。审批模式决定工具执行；合同接受仍需明确决定。目标产品应先交付待确认报告，避免无限等待商业决策。测试可以提供明确标注的模拟答案，不代表真实授权。

## 平台与团队边界

平台提供通用安装、原文访问、委派、模型路由、工具执行与产物交付。团队负责合同推理、范围、证据、覆盖、评分和建议措辞。内容问题修改成员/规则资产；通用能力故障修改 DesireCore。本地辅助脚本可用于诊断导出问题，不能替代团队自主导出成功。

## 证据状态

9 月 15–16 日的 C07 本地历史观察覆盖 O0–O4 和部分 O5，使用 `desirecore-cloud/qwen3.8-flash`，记录 38 项 confirmed 和两项 additional。62/100 是合同评分。C07 为合成样本；YAML 经人工修复，DOCX 经外部脚本生成；干净 PDF 导出不能证明可见修订显示通过。

仓库未包含上述观察可公开复验的 run 日志包。它们可用于排查，不能证明自主全流程、真实签署合同或生产就绪。[测试说明](testing.zh-CN.md) 给出补齐证据的要求。
